# Практика 2

Эксперименты с длительностью обучения и весами награды для роботизированного переноса куба. 

## Результаты

| Эксперимент | Изменение                       | mean_reward обучения | SR | Время обучения |
|---|---------------------------------|---:|---:|---:|
| Baseline | Исходные параметры              | 1386.83 | 10/10 | 32:32 |
| Checkpoint 500 | Промежуточный чекпоинт baseline | 1060.66 | 7/10 | 16:59 |
| Опыт A | box_target: 8 => 40             | 1046.83 | 0/10 | 74:52 |
| Опыт B | robot_target_qpos: 0.3 => 30    | 4532.60 | 0/10 | 64:54 |
| Самостоятельный опыт | box_target: 8 => 4              | 1002.36 | 10/10 | 77:43 |

**[Полная таблица экспериментов](assets/readings/experiments.md)** содержит настройки, различия с baseline и наблюдения поведения.

Первая попытка остановилась с NaN в награде; в итоге просто перезапустил обучение без изменений :D, и предоставленный финальный журнал доходит до итерации 1000. Причина ошибки не установлена.

## Структура материалов

- `assets/readings/` - отчёты уроков 4-7 и сводная таблица экспериментов.
- `assets/images/` - сравнительные графики обучения.
- `assets/videos/` - пять записей инференса по десять эпизодов.
- `training/` - журналы TensorBoard и конфиги запусков.

Главный вывод: высокий mean_reward не гарантирует выполнение задачи. При усилении награды за стартовую позу reward вырос, но SR стал 0/10; при уменьшении box_target награда снизилась, а SR сохранился 10/10. Для выводов о выполнении задачи используются SR и наблюдаемое поведение. Оценка на десяти эпизодах и по одному завершённому обучению на вариант не доказывает устойчивость эффекта.
