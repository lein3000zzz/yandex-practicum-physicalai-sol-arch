# Урок 7: самостоятельный эксперимент

## Исследовательский вопрос

Сохранит ли политика способность доставлять куб к цели, если уменьшить вес box_target вдвое относительно baseline, с 8.0 до 4.0?

## Предварительная гипотеза

Если уменьшить box_target с 8.0 до 4.0 при остальных исходных настройках, то финальный mean_reward будет ниже baseline, а SR останется в пределах 8-10/10, поскольку вклад доставки в награду уменьшится, но поощрение переноса сохранится и не будет доминировать настолько сильно, как в опыте с весом 40.0.

| Поле | Зафиксированное предсказание |
|---|---|
| Изменение | 8.0 => 4.0, уменьшение вдвое; точная строка `env_cfg.reward_config.scales.box_target = 4.0` |
| Ожидание по mean_reward | Финальный Train/mean_reward < 1386.83 - ниже baseline |
| Ожидание по SR | 8-10 успешных эпизодов из 10 - ухудшение не более чем на два успеха относительно baseline |
| Обоснование | Понижаем вклад доставки, сохраняя положительную награду за неё; проверяем, сохранится ли решение задачи при изменённом балансе основной награды |

Опыт box_target=40.0 дал SR=0/10, но из этого не следует, что 4.0 обязательно лучше. При меньшем весе модель тоже может предпочесть приближение к кубу без переноса. Гипотеза будет оценена по фактическим результатам, а не переписана после их просмотра.

## Результат и сопоставление с гипотезой

Гипотеза: при box_target=4.0 финальный mean_reward ниже baseline, SR остаётся в пределах 8-10/10.

| Метрика | Baseline | box_target=4.0 |
|---|---:|---:|
| Финальный mean_reward обучения | 1386.83 | 1002.36 |
| SR, 10 эпизодов | 10/10 | 10/10 |
| Подъём куба выше 0.2 м | 10/10 | 10/10 |
| Время цикла обучения, TensorBoard | 1952 с | 4663 с (77 мин 43 с) |

Подтверждение по mean_reward: да. Разница -384.48 (-27.72%). Подтверждение по SR: да; ожидалось 8-10/10, измерено 10/10. Разница с baseline: +0 успехов из 10.

### Поведение, объяснение и практический вывод

На кадрах, извлечённых из записанного видео, робот подходит к кубу, поднимает его и удерживает возле цели. Численная оценка подтверждает подъём и доставку во всех десяти эпизодах; финальное расстояние составляет 0.004-0.024 м.

Гипотеза подтвердилась по обоим критериям: mean_reward снизился, SR остался 10/10. Метрики согласуются с предварительным ожиданием: снижение численного вознаграждения при изменении его весов не означает ухудшения выполнения задачи. В этом запуске положительного веса box_target=4.0 оказалось достаточно для обучения переносу вместе с остальными компонентами награды. Это согласуется с предполагаемым механизмом, но не доказывает единственную причину результата.

Практический вывод: для полученной модели уменьшение box_target вдвое сохранило доставку на выбранных десяти эпизодах. Нельзя выбирать веса только по максимальному mean_reward: опыт qpos_strong имел более высокую награду и SR=0/10, а здесь меньшая награда сочетается с SR=10/10.
